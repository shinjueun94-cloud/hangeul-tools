Side project · seven browser tools

Adults learn the letters first. A six-year-old won't.

For years I only taught Korean to adults, where you start at consonants and vowels and build upward, and it works. Then I taught a six-year-old bilingual child and none of it applied. She learned by ear, lost interest in minutes, and disliked being taught letters. She still needed them, the same way an English-speaking child still needs the alphabet. These seven tools are my attempt to make that part worth sitting through.

Why these exist

One of these I got wrong first.

The problem

Teaching adults, the order is obvious: consonants, vowels, then syllables. Nobody objects to starting at the beginning.

A six-year-old objects. She wanted to listen and speak, her attention ran out in minutes, and letters were the boring part. Skipping them wasn't an option, so the letters had to stop feeling like the price of admission.

What I got wrong

My first tool was a builder: drag the consonants and vowels you know into a frame and assemble a syllable. It quietly assumed she already knew the letters. She didn't. That was the entire problem I was trying to solve.

So I built the opposite direction. Start from a word she already recognises, then pull it apart into syllables, then into letters. Familiar thing first, system underneath it second.

What that changed

Once the word came first, no tool could ship with a fixed word list. The word has to be whatever she already knows this week, so I type it in during the lesson and the tool generates the exercise from it.

That gave every tool the same awkward requirement: one screen that has to work for both of us at once. Me setting the exercise up mid-lesson, and her doing it a second later.

How it's built

Plain files, on purpose.

  • StackOne self-contained HTML file per tool. No framework, no build step, no backend.
  • AudioWeb Speech API, using the browser's own Korean voice. No recorded audio to maintain.
  • Built withWritten hands-on with AI assistance, then reshaped as lessons showed what wasn't working.
  • Tested byThe children I tutor, in live one-to-one and small-group lessons.

Two things I chose not to build.

Anything I add during a lesson lasts until the tab closes, and then it's gone. That was as much memory as a lesson needed, so I never built more.

There's no account and no history, and no way to hand a prepared set to anyone else. Nothing stops a parent using these, but they'd be starting from scratch every time.
